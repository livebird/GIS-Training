Module 3.5 · General idea, platform names vary

A dataset is stored; a layer uses it; a map stacks layers

Software often shows all three with one icon and one name, which is why beginners delete data by mistake — or think they have. Learn the three words, see one dataset shown two ways, and watch how the order of layers can hide six of seven complaints.

In this module you will

  • Tell a dataset (stored rows) from a layer (a use of those rows in a map) from a map (a stack of layers).
  • Put two layers on one dataset, edit the dataset, and watch both change — then make a copy and watch it not change.
  • Reorder layers and see drawing order hide data without deleting anything.

The defining fact, straight from Esri’s documentation: layers “reference a data source” — they point at data, they do not hold a copy — and “you can use the same imagery layer in every map you create”. Chapter 2 said the same about projects. Delete the layer: the dataset is untouched. Delete the dataset: every layer on it is broken.

A quiet trap

Many tools take the layer’s current selection and filter as their input. Copy Features copies only the selected rows when a selection exists; Get Count counts only the selected rows. A copy made from a filtered layer is a copy of the filtered set — which may be exactly what you wanted, or four rows silently lost. Record which you used, and for a copy, the date and the filter.

3.5.3Basemap, working layers, and drawing order

Maps usually have two kinds of layer. A basemap is context — streets, terrain, satellite imagery — someone else’s data shown for orientation, not yours to edit. Operational layers (working layers) are the data you select, query and edit: requests, assets, wards. Our practice town has no basemap, because the grid has no place on the Earth for one to line up with (Chapters 5–6). Everything you see here is working data.

Layers draw from the bottom of the list upward: “the layer lowest in the list draws first … until the features in the topmost layer draw above all else”. A layer higher in the list covers whatever is beneath it. Reorder the list and count the visible complaints.
