Module 1.5

Layers and map interaction

A layer is one kind of record drawn on the map. Turn it off and the records are still there.

In this module you will

  • Toggle layers, pan, zoom, and select a record on a practice map.
  • Explain the difference between hiding, removing, and deleting.
  • Keep an observation log (a short set of notes): what the map suggests, what the table confirms, what stays uncertain.

1.5.1Layers, and a first walk around a map

A layer is a set of records of one kind drawn together. The Gentle Introduction to GIS says map layers “are stored as files on a disk or as records in a database”, each representing “something in the real world — a roads layer for example”; when several are added, “the layers are overlaid on top of each other”; and the layers list lets you “re-order, hide, show and group layers”. The ArcGIS Pro documentation states the key principle: “Layers in a map reference the source dataset, but do not control the data.” In plain words: a layer points to the stored table; it is not a copy of it.

Eight things to do and notice

  1. Look at the layer list. The order in the list is the drawing order — the top layer draws on top.
  2. Turn Wards off, then on. Requests and road do not move. Nothing was deleted.
  3. Turn Roads off. P5 now looks like an ordinary dot on the ward edge. The fact that it is on the road disappears from view. Hidden information changes what a map seems to say.
  4. Zoom in on P5. The dot still sits on the ward edge, but the dot’s size is in screen pixels, not metres — it does not shrink as you zoom. “On the line” is a claim about the coordinates, not about the picture.
  5. Pan east to P6. It is beyond both wards and past the end of the road.
  6. Click P5. The selection count changes and the record is highlighted.
  7. Tick “Show selected records only”. The table row for P5 shows exactly the same values. Map and table are two views of one record.
  8. Clear the selection.
Doing the same in ArcGIS Pro (from the official documentation; not execution-tested)
  • Layers: the Contents pane lists them; use the check box to turn one on or off.
  • Navigate: on the Map tab, Navigate group, use the Explore tool. Drag to pan; mouse wheel to zoom; the Insert key zooms to full extent; right-click a layer → Zoom To Layer.
  • Select: Map tab, Selection group. The number selected appears at the bottom of the view. Clear is in the same group.
  • Table: right-click the layer in Contents → Attribute Table (or Ctrl+T). Use Show Selected Records / Show All Records at the bottom of the table.
Doing the same in QGIS 3.40 (from the official user manual; not execution-tested)
  • Layers: the Layers panel with check boxes.
  • Navigate: Pan Map tool — hold the left button and drag; or hold Space and move the mouse. Roll the wheel to zoom. Zoom Full; Zoom To Layer(s).
  • Select: Select Features by area or single click; clear with Deselect Features from All Layers (Ctrl+Alt+A). Identify Features (Ctrl+Shift+I / Cmd+Shift+I) reads a feature’s values without selecting it.
  • Table: right-click the layer → Open Attribute Table (F6; Shift+F6 opens it filtered to the selection). Selecting a row selects the feature and vice versa.

1.5.2Hiding is not deleting

Unticking a layer changes what you see. It does not change what is stored. There are three different levels, and they are easy to mix up.

There is a fourth, less obvious level: a filter (Chapter 10) can hide some records of a layer — say, only Open requests are drawn. A filtered map can look complete and be missing half the data. Any map handed to a manager must say which records were left out and why.

Developer view

Turning a layer off is collapsing a panel in the UI. Removing a layer is dropping a SQL view. Deleting the dataset is dropping the table. Exact for the first two; weaker for the third, because GIS datasets are often single files on a shared drive with no transaction log — “drop table” can be far harder to undo than in a database.

Misconception

“I unticked the duplicates, so the count on the map is right now.” The number of records has not changed; only the drawing has. Any tool that counts the layer will still count the hidden ones unless a filter or selection is applied.
